# Links de STL para os 100 produtos

Pesquisa de 27/11/2026 para os produtos da [`planilha-precos-impressao3d.xlsx`](planilha-precos-impressao3d.xlsx). **A licença de cada link foi lida na própria página do modelo** (Printables, Thingiverse e MakerWorld), com o [Firecrawl](https://github.com/firecrawl/firecrawl).

Material considerado: **PETG Masterprint** (veja a seção "Material" do [README](README.md)). Todos os modelos abaixo servem em PETG. Nos de encaixe impresso já montado (print-in-place), teste antes, porque o PETG fecha folgas pequenas.

**Antes de vender:** abra o link, tire um print do campo "License" com a data e guarde. O autor pode mudar a licença depois.

| Licença | Pode vender? |
|---|---|
| **CC0** (domínio público), **MIT** | ✅ Sim, sem condições |
| **CC BY** | ✅ Sim, dando crédito no anúncio (ex.: "Design: Kiesling, CC BY") |
| **CC BY-SA** | ✅ Sim, com crédito. Se modificar o arquivo, o arquivo novo fica com a mesma licença |
| **GPL v3** | ✅ Sim. Se distribuir o arquivo modificado, ele precisa continuar GPL |
| Qualquer licença com **NC** (não comercial), **Standard Digital File License** ou **MakerWorld Exclusive** | ❌ Não |
